# Simulador Monte Carlo - Pokémon TCG Pocket

¿Alguna vez te preguntaste cuántos sobres necesitas abrir para completar tu álbum de Pokémon TCG Pocket?

Este simulador usa el método Monte Carlo para correr miles de simulaciones de apertura de sobres y calcular:
- Probabilidad de completar el álbum
- Promedio de sobres necesarios
- Mejor y peor escenario
- Cuántos sobres te faltan según lo que ya tienes

Solo pon cuántas cartas te faltan, cuántos sobres piensas abrir, y el simulador hace el resto.

Hecho para coleccionistas de Pokémon TCG Pocket que quieren planear sus sobres sin gastar a lo loco.
